# Нейросеть для распознавания документов на Python (с веб-интерфейсом)

Проект разработан для автоматизации ввода данных в сфере гостиничного дела (распознавание паспортных данных клиентов, скан-копий договоров и заявлений).

## Принцип работы программы (Отчет)
Программа работает по принципу конвейера обработки изображений и текста (Pipeline):
1. **Модуль веб-интерфейса (Gradio):** Предоставляет пользователю удобную форму в браузере для загрузки графических файлов (сканов или фотографий документов).
2. **Модуль предобработки (OpenCV):** Входное изображение переводится в оттенки серого, после чего применяется адаптивная бинаризация методом Оцу (Otsu's Thresholding). Это удаляет серый фон, блеклые тени и делает печатный текст контрастным (строго чёрные буквы на белом фоне) для повышения точности OCR.
3. **Нейросетевой модуль (EasyOCR):** Предварительно обученная глубокая нейросеть (архитектура на базе ResNet + LSTM) выполняет детекцию текстовых блоков на картинке и посимвольно распознает печатный текст на русском и английском языках.
4. **Пост-обработка:** Алгоритм фильтрует результаты по порогу уверенности (`confidence > 0.20`), отсекая случайные цифровые шумы, и структурирует строки для вывода на экран.

## Как запустить проект на компьютере:

1. **Скачайте этот репозиторий** себе на компьютер.
2. Откройте терминал в папке проекта и **установите библиотеки**:
   ```bash
   pip install -r requirements.txt
   ```
3. **Запустите программу**:
   ```bash
   python main.py
   ```
4. После запуска терминал выдаст локальную ссылку (например, `http://127.0.0.1:7860`). Откройте её в браузере, чтобы перейти в веб-интерфейс.
