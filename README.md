# Нейросеть для распознавания документов на Python

Скрипт использует предобученную нейросеть **EasyOCR** для распознавания печатного текста (русский/английский) и библиотеку **OpenCV** для улучшения читаемости блеклых сканов.

## Как запустить проект на компьютере:

1. **Скачайте этот репозиторий** себе на компьютер.
2. Откройте терминал (командную строку) в папке проекта и **установите библиотеки** одной командой:
   ```bash
   pip install -r requirements.txt
   ```
3. Положите фото или скан вашего документа в эту же папку и назовите файл **`scan_document.jpg`**.
4. **Запустите нейросеть**:
   ```bash
   python main.py
   ```
